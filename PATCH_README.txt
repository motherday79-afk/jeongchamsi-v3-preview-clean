이번 범위
1) 세대별 대통령 모의투표

- 검색결과의 '바로 선택' 클릭 시 해당 인물이 select에 즉시 선택됨
- 서버 검색 호출 없음: 이미 로드된 후보 select를 클라이언트에서 필터

2) 메인 시민들의 선택
- 메인에서는 절대 투표하지 않음
- 최대 3개 선택지만 미리보기
- 항목 클릭 → /poll?pollId=...&option=...
- 설문페이지에서 전체 선택지(최대 10개) 확인 후 '투표 확인'으로 최종 투표
- 메인에서 누른 항목은 상세페이지에서 미리 선택된 상태로 표시하되 자동 투표는 하지 않음

3) 통합검색
- 현재 정치인/정당 검색 UI는 유지
- 정참시 NEWS / COLUMN / IT’S ME / 정뮤니티 / 전국평가제 섹션을 항상 카테고리별로 구성
- 실제 관련 콘텐츠가 있으면 최대 5개 미리보기 + 전체보기
- 아직 데이터가 없으면 '노출 예시'임을 명확히 표시한 빈 결과 예시 카드
- 민주당/더불어 민주당/더불어민주당, 국힘/국민의 힘/국민의힘 등 기존 별칭 정규화 유지
- 게시판 전체보기의 ?q= 검색어 필터도 지원
