이번 패치의 목적

구조 수정
1. 메인 NOW TOP15 경량화
   - 메인은 543명 전체 정치인 데이터 파일을 첫 렌더에서 파싱하지 않음.
   - 첫 화면에 필요한 15명만 home-person-preview.js로 분리.
   - 전체 543명 데이터는 NOW/검색/상세 또는 최근 본 정치인 데이터가 실제 필요할 때 로드.

2. 로그인 세션과 메인 첫 렌더 병렬화
   - 기존: 세션 확인 완료 → 메인 렌더.
   - 변경: 일반 공개 페이지에서는 세션 확인과 메인 렌더를 병렬 시작.
   - 로그인/회원가입/마이페이지/관리자/글쓰기 등 권한이 필요한 페이지는 기존처럼 세션 확인 후 렌더.

3. 로그인 사용자 UI 정확도 보존
   - 첫 렌더 중에는 jcv3-user-pending 상태로 로그인 의존 UI를 임시 상태로 표시.
   - 세션 확인 완료 후 즉시 동일 페이지를 한 번 재렌더하여 실제 회원/최근 본 정치인 정보 반영.
   - 공개 정치 콘텐츠는 세션 응답을 기다리지 않음.

4. 최근 본 정치인/전국평가
   - 메인 첫 paint에서는 전체 543명 provider를 강제로 로드하지 않음.
   - 세션 확인 뒤 실제 최근 본 인물 또는 평가 대상이 있을 때만 동적 로드.
