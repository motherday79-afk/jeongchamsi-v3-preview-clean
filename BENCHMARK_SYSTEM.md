# alpha6.0.35 BENCHMARKED PRODUCT SYSTEM

## What changed
This build deliberately starts from alpha6.0.30 STANDARD FULL CLEAN and changes the visual system, not the product core.

## Reference principles extracted before design
- AJD: many service categories are allowed, but they live inside one brand grammar. The homepage reveals complexity progressively: problem → solution → service choice → proof/reviews.
- Mintit: the first decision is small and explicit (ATM vs Home). Pricing, ranking, benefits, reviews and process follow later rather than competing at the top.
- Toss: each section has one dominant message and one dominant visual/action. Strong whitespace and repeated typography make very different financial products feel like one family.
- Ohouse: global search and category navigation organize a very wide service/catalog surface before the user reaches dense content.

## Applied to JEONGCHAMSI
1. Removed the old icon-launcher row from the first impression.
2. Combined wordmark, primary navigation, search and utilities into one header system.
3. Added a single brand hero that contains actual product data (NOW + poll), not decorative AI artwork.
4. Added a six-service launcher with one card grammar and only three controlled accent surfaces.
5. Reordered home emphasis: NOW → citizens' choice → IT'S ME → reading/community → deeper tools.
6. Kept editorial styling only for editorial content; interactive tools use product UI styling.
7. No generated illustration, no decorative gradients, no duotone icon family, no rainbow card system.
