# alpha6.0.36 — Political Spectrum Palette

Color-only hotfix on alpha6.0.35.2. No layout, DOM structure, routing, data, spacing or typography changes.

Principle: neutral large surfaces + restrained spectrum accents.
- Blue: information / NOW
- Red: citizen choice / attention
- Orange: participation / action
- Teal: civic identity / IT'S ME
- Navy: analysis / comparison
- Green: evaluation / status

Source party colors were deliberately softened/reinterpreted so no single party identity dominates the product.
